## توضیحات پروژه 📌
<!-- Project Description : استاندارد  -->
این پروژه یک بورد صوتی (Sound Board) تعاملی است. با لود شدن صفحه، چندین دکمه به‌صورت پویا توسط جاوااسکریپت تولید می‌شوند؛ با کلیک بر روی هر دکمه، صدای مربوطه پخش شده و در صورت پخش بودن صدای دیگر، صدای قبلی به‌طور خودکار متوقف می‌گردد.

## ویژگی ها  
<!-- Features : استاندارد -->
- تولید داینامیک دکمه‌ها از روی آرایه داده‌ها در جاوااسکریپت
- مدیریت و توقف خودکار صداهای قبلی قبل از پخش صدای جدید (`stopSongs`)
- مدیریت المان‌های چندرسانه‌ای HTML5 Audio بدون وابستگی به کتابخانه‌ها
- طراحی زیبا، متمرکز و ریسپانسیو با Flexbox
- کدنویسی تمیز، سبک و ماژولار

## Project Description 📌
<!-- Standard : Project Description  -->
This project implements an interactive Sound Board. Upon loading, buttons are dynamically generated via JavaScript. Clicking any button plays its corresponding audio clip, automatically halting any previously playing audio to ensure clean single-channel playback.


---
---
---

## Features 🌏
<!-- Standard : features  -->
- Dynamic button generation from an array of identifiers in JavaScript
- Automatic interruption and resetting of active audio tracks (stopSongs)
- HTML5 Audio API integration without external dependencies
- Centered and responsive UI layout powered by Flexbox
- Clean, modular, and lightweight codebase
